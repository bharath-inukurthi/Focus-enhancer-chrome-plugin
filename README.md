# Focus Enhancer Chrome Extension

🚀 **Focus Enhancer** is a Chrome extension designed to boost your productivity. Enter a website URL to block, and the extension will display a motivational message whenever you try to visit that site.

## 🛠️ Installation Guide
1. **Download or Clone** this repository:
   ```bash
   git clone https://github.com/yourusername/focus-enhancer.git
   ```
2. **Open Chrome** and navigate to:
   ```
   chrome://extensions/
   ```
3. **Enable Developer Mode** (top-right corner).
4. **Click 'Load Unpacked'** and select the `focus_enhancer` folder.

## 🚀 Usage Instructions
1. **Open the extension** via the Chrome toolbar.
2. **Enter the URL** of the site you want to block (e.g., `www.facebook.com`).
3. **Save the URL.**
4. Whenever you visit the blocked site, you will see a **motivational message** encouraging you to stay focused.

## 💡 Features
- ✅ **Block unlimited sites** based on user input.
- ✅ Display **custom motivational messages**.
- ✅ Simple and lightweight design.

## 📝 Customization
- Change the motivational message by editing `blocked/blocked.html`.
- Modify styles via `styles/styles.css`.
